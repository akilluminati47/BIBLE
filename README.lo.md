BIBLE ແມ່ນໂປຣແກຣມບູດທີ່ RIPPS2 ຕັ້ງໃຫ້: ເປັນ fork ຂອງ PS2BBL Extended ຂອງ saildot4k.

**fork ນີ້ປ່ຽນຫຍັງແດ່**

- ໜ້າເປີດ: ໂລໂກ້ PS2 ຢູ່ກາງທ້ອງຟ້າຂອງ RIPPS2, ມີປຸ່ມຢູ່ລຸ່ມ ແລະ ຂໍ້ຄວາມໃດໆຢູ່ເທິງ.
  `BIBLE_GLYPHS` 0 ບໍ່ມີ, 1 ປຸ່ມດ້ານໜ້າ (ຄ່າເລີ່ມຕົ້ນ), 2 ທັງສິບຫົກປຸ່ມເປັນສອງແຖວ ແຖວລະແປດ.
  `BIBLE_INFO` 1 ສະແດງຂໍ້ມູນເຄື່ອງ, ໂມງ ແລະ ການນັບຖອຍຫຼັງ (ປິດໄວ້ເປັນຄ່າເລີ່ມຕົ້ນ).
  ທ້ອງຟ້າກົງກັບ Color Theme ຂອງ RIPPS2 ຂອງທ່ານ: ເມື່ອບໍ່ມີ `BIBLE_COLOR`, BIBLE ຈະອ່ານທ້ອງຟ້າທີ່ RIPPS2 ບັນທຶກໄວ້ກັບ
  ການຕັ້ງຄ່າຂອງມັນ, ຈາກໂຟນເດີ RIPPS2 ທີ່ລາຍການ AUTO ຂອງມັນເປີດ (`BIBLE_COLOR` ໃນການຕັ້ງຄ່າມີສິດກ່ອນ).
  ໜ້າຕາດຽວກັນໃນທຸກໂໝດວິດີໂອ. ໜ້າຕ່າງໆ (ໂໝດວິດີໂອ, ລາຍຊື່ຜູ້ສ້າງ, ປຸ່ມເປີດໂປຣແກຣມ) ຄ່ອຍໆປາກົດທັບໂລໂກ້ທີ່ຫຼີ່ລົງ
  ໂດຍເກັບປຸ່ມໄວ້, ເພື່ອໃຫ້ອ່ານປຸ່ມເປີດໂປຣແກຣມໄດ້ສະບາຍໆ.
- ໂໝດວິດີໂອ: `VIDEO_MODE` ຮັບ `576P`, `720P` ແລະ `1080I` ນຳ, ເຊິ່ງແມ່ນໂໝດທີ່ເຫຼືອຂອງ RIPPS2. `AUTO` (ຄ່າເລີ່ມຕົ້ນ)
  ເລີ່ມໃນ Video Mode ຂອງ RIPPS2 ເມື່ອພົບການຕັ້ງຄ່າຂອງມັນຢູ່ຂ້າງລາຍການ AUTO, ຖ້າບໍ່ດັ່ງນັ້ນໃຊ້ໂໝດຂອງເຄື່ອງເອງ.
- `BIBLE_WIDESCREEN`: `AUTO` (ຄ່າເລີ່ມຕົ້ນ: Widescreen ຂອງ RIPPS2, ຖ້າບໍ່ດັ່ງນັ້ນການຕັ້ງຈໍ 16:9 ຂອງ PS2), `ON` ຫຼື
  `OFF`. ໃນ 480i, 576i, 480p ແລະ 576p ໜ້າເປີດຈະແຕ້ມສຳລັບໂທລະທັດທີ່ຢືດພາບເປັນ 16:9, ໂດຍບໍ່
  ບີບ. 720p ແລະ 1080i ເປັນ 16:9 ຢູ່ແລ້ວ.
- ບໍ່ກະໂດດຕອນເຂົ້າ RIPPS2: ຕອນເປີດ ໂລໂກ້ ແລະ ປຸ່ມຈະຈາງໄປ ສ່ວນທ້ອງຟ້າຍັງຢູ່ເທິງຈໍ, ໃນໂໝດຂອງ RIPPS2;
  RIPPS2 ເລີ່ມເທິງທ້ອງຟ້າດຽວກັນນັ້ນ. ກົດ TRIANGLE + CROSS ຄ້າງໄວ້ຕອນເປີດເຄື່ອງສຳລັບໜ້າໂໝດວິດີໂອ, ເຊິ່ງເປີດສະເໝີ
  ໃນໂໝດ interlaced ຂອງເຄື່ອງເອງ (ທາງກັບຄືນຈາກ 720p ຫຼື 1080i ໃນສາຍ composite).
- ໃໝ່: ໜ້າປຸ່ມເປີດໂປຣແກຣມ. ກົດ L2 + R2 ຄ້າງໄວ້ຕອນເປີດເຄື່ອງເພື່ອອ່ານເສັ້ນທາງເປີດຂອງທຸກປຸ່ມ, ບໍ່ວ່າການຕັ້ງຄ່າໜ້າເປີດຈະເປັນແນວໃດ.
- ປຸ່ມປະສົມທີ່ກົດຄ້າງໄວ້ຕັ້ງແຕ່ເປີດເຄື່ອງ ດຽວນີ້ເປີດໜ້າຂອງມັນໄດ້ແລ້ວ (TRIANGLE + CROSS ເຄີຍຫຼຸດໄປ ຕອນທີ່ຈອຍຍັງ
  ກຳລັງເລີ່ມ).
- ອະນຸຍາດ `KEY_READ_WAIT_TIME = 0` (ຄ່າຕ່ຳສຸດຂອງ upstream ແມ່ນ 500 ms).
- ລຸ້ນສ້າງ PS2 ສຳລັບບັດໜ່ວຍຄວາມຈຳ / USB, MMCE, MX4SIO ແລະ HDD. ບໍ່ລວມ eGSM ຂັ້ນທີ 2.

**RIPPS2 ໃຊ້ມັນແນວໃດ**

## ການຕັ້ງຄ່າ ແລະ argument

ແກ້ໄຂໄຟລ໌ຕັ້ງຄ່າຕາມຕ້ອງການ. ແນະນຳ [R3Configurator](https://github.com/saildot4k/R3CONFIGURATOR) ສຳລັບແກ້ໄຂໄຟລ໌ຕັ້ງຄ່າ. ເສັ້ນທາງຖືກຕັ້ງໄວ້ລ່ວງໜ້າໃຫ້ກົງກັບການດາວໂຫຼດຈາກ [PS2 Homebrew Store](https://ps2homebrewstore.com). ສະນັ້ນທ່ານພຽງແຕ່ແກ້ໄຂຕົວເລືອກ Auto ແລະ ດີທີ່ສຸດແມ່ນຕັ້ງ argument ຂອງ NHDDL ຕາມອຸປະກອນທີ່ທ່ານໂຫຼດ ISO.

<a id="config-path-search-order"></a>

### ລຳດັບການຊອກຫາການຕັ້ງຄ່າ

ການຊອກຫາການຕັ້ງຄ່າດຽວນີ້ຮູ້ຈັກປະເພດການບູດ ເພື່ອບໍ່ໃຫ້ໂຫຼດໄດຣເວີທີ່ບໍ່ຈຳເປັນຕອນເລີ່ມ:

1. `CONFIG.INI` (CWD: ໂຟນເດີເຮັດວຽກປັດຈຸບັນ)
2. ເມື່ອໂຫຼດຈາກອຸປະກອນ:
   - ບູດຈາກ MMCE: `mmce?:/PS2BBL/CONFIG.INI`
   - ບູດຈາກ MX4SIO: `mx4sio:/PS2BBL/CONFIG.INI`
   - ບູດຈາກ APA HDD: `hdd0:__sysconf:pfs:/PS2BBL/CONFIG.INI`
   - ບູດຈາກ BDM: `usb:/PS2BBL/CONFIG.INI` / `mass:/PS2BBL/CONFIG.INI` / `ata:/PS2BBL/CONFIG.INI`
3. ສຳຮອງໃນບັດໜ່ວຍຄວາມຈຳ:
   - ໃນ PS2: `mc?:/SYS-CONF/PS2BBL.INI`
   - ໃນ PSX-DESR: `mc?:/SYS-CONF/PSXBBL.INI`
4. ສຳຮອງສຸດທ້າຍໃນ PSX
   - `xfrom:/PS2BBL/CONFIG.INI`
5. ເມື່ອຄອມໄພລ໌ດ້ວຍ `DISC_STOP_AT_BOOT=1
   - `cdrom0:/PS2BBL/CONFIG.INI`
   - ສຳຮອງໃນບັດໜ່ວຍຄວາມຈຳຕາມຂໍ້ 3 ຂ້າງເທິງ.

<a id="device-path-prefixes"></a>

### ຄຳນຳໜ້າເສັ້ນທາງອຸປະກອນ
PS2BBL ຮອງຮັບຄຳນຳໜ້າເສັ້ນທາງເປີດ/ຕັ້ງຄ່າເຫຼົ່ານີ້:
- `mc0:/`, `mc1:/`, `mc?:/`
- `usb:/` (ແນະນຳ) ແລະ `mass:/` (ເກົ່າ)

<a id="build-specific"></a>

#### ຕາມລຸ້ນສ້າງ:  
- `mmce0:/`, `mmce1:/`, `mmce?:/` __ລຸ້ນສ້າງ MMCE__
- `mx4sio:/` (ແນະນຳ) ແລະ `massX:/` (ເກົ່າ)  __ລຸ້ນສ້າງ MX4SIO__
- `hdd0:partition:pfs:/<path to elf>` __ລຸ້ນສ້າງ HDD__
- ເສັ້ນທາງ `xfrom:/` __ລຸ້ນສ້າງ PSX DESR__
- `ata:/` ອຸປະກອນ BDM ສຳລັບ HDD exFAT
- `ilink:/` (ຮາກບ່ອນເກັບຂໍ້ມູນ BDM) __ຍັງບໍ່ໄດ້ສ້າງ__
- `DISC_STOP_AT_BOOT=1` ໂປຣໄຟລ໌ຄອມໄພລ໌ທີ່ຢຸດແຜ່ນສະເໝີຫຼັງໂຫຼດການຕັ້ງຄ່າ

### LOGO_DISPLAY
ໃຊ້ `LOGO_DISPLAY = 3` ເພື່ອສະແດງຊື່ປຸ່ມ. ຊື່ກຳນົດດ້ວຍ `NAME_<BUTTON>`.
  - `0` ບໍ່ມີໂລໂກ້ ແລະ ຂໍ້ມູນເຄື່ອງ
  - `1` ຂໍ້ມູນເຄື່ອງ
  - `2` ໂລໂກ້ PS2BBLE/PSXBBLE ແລະ ຂໍ້ມູນເຄື່ອງ
  - `3` ກຣາຟິກປຸ່ມທີ່ມີ `NAME_BUTTON = <TITLE>` ຈາກໄຟລ໌ຕັ້ງຄ່າ
    - ຕົວຢ່າງ:
      ```
      NAME_SQUARE = POPSLOADER
      ```

<a id="custom-splash-logo-from-cwd"></a>

#### ໂລໂກ້ໜ້າເປີດເອງຈາກ CWD
ຖ້າພົບໄຟລ໌ໂລໂກ້ເອງ (LOGO.BIN) ໃນ CWD (ໂຟນເດີເຮັດວຽກປັດຈຸບັນ), ມັນຈະແທນໂລໂກ້ PS2BBLE/PSXBBLE ທີ່ຝັງໄວ້.

ແປງ PNG ເປັນໄຟລ໌ດິບທີ່ຕ້ອງການ:
  - PNG ຕ້ອງເປັນ RGBA 8 bit ແບບດັດຊະນີ, 255 ສີຕໍ່ຊ່ອງ ແລະ ຄວາມລະອຽດ 256x64.

  - ຊຸດເຜີຍແຜ່ (ສະຄຣິບຢູ່ຮາກຂອງຊຸດເຜີຍແຜ່):
  ```bash
  python png_to_logo_rbga.py my_logo.png
  ```

  - ວາງ `LOGO.BIN` ທີ່ສ້າງໄວ້ຂ້າງ PS2BBL Extended. ຄວນເປັນ `mc?:/BOOT/` ຖ້າໃຊ້ການດາວໂຫຼດຈາກ [PS2 Homebrew Store](https://ps2store.com)

<a id="retrogem-visual-game-id"></a>

### ID ເກມແບບພາບຂອງ Retrogem
- `APP_GAMEID = 1` ເປີດ ID ເກມແບບພາບສຳລັບແອັບ/homebrew, ສູງສຸດ 11 ຕົວອັກສອນຈາກຊື່ໄຟລ໌ ຫຼື ແຜ່ນ PS1/2
- `CDROM_DISABLE_GAMEID = 1` ປິດ ID ເກມແບບພາບສຳລັບແຜ່ນທີ່ເປີດຜ່ານ `cdrom`.

<a id="disc-spin-control"></a>

### ການຄວບຄຸມການໝູນແຜ່ນ
- ກະແຈ/ຄ່າທົ່ວໄປ: `DISC_STOP = 0/1`
- `DISC_STOP = 1` ຢຸດແຜ່ນຫຼັງໂຫຼດການຕັ້ງຄ່າ ເມື່ອພົບໄຟລ໌ຕັ້ງຄ່າ.
- `DISC_STOP = 0` (ຫຼື ບໍ່ໃສ່) ຮັກສາພຶດຕິກຳເລີ່ມຕົ້ນ.
- ສາມາດເພີ່ມ `-disc_stop` ໃສ່ແຕ່ລະລາຍການເພື່ອຢຸດແຜ່ນຫຼັງພົບ ELF ເປົ້າໝາຍ.

<a id="video-mode"></a>

### ໂໝດວິດີໂອ
- `VIDEO_MODE = AUTO, NTSC, PAL, 480P` ໃຊ້ຄ່າເລີ່ມຕົ້ນຂອງ PS2 ຫຼື ບັງຄັບໜຶ່ງໃນອີກ 3 ໂໝດ.

<a id="emergency-video-mode-selector"></a>

#### ຕົວເລືອກໂໝດວິດີໂອສຸກເສີນ
- ເຂົ້າດ້ວຍ `TRIANGLE + CROSS` ລະຫວ່າງບູດ
- ຕົວເລືອກບັງຄັບ `LOGO_DISPLAY = 3` ຂະນະເປີດຢູ່ ເພື່ອໃຫ້ທ່ານເຫັນໂລໂກ້ ແລະ ປຸ່ມ.
- ການຄວບຄຸມ:
  - `LEFT/RIGHT` ສະຫຼັບໂໝດ: `AUTO`, `NTSC`, `PAL`, `480P`
  - `SELECT` ບັນທຶກໂໝດທີ່ເລືອກລົງໄຟລ໌ຕັ້ງຄ່າທີ່ໃຊ້ຢູ່
  - `START` ອອກຈາກຕົວເລືອກ ແລະ ໄປຕໍ່ທີ່ໜ້າສະແດງປຸ່ມ

<a id="cdrom-launch-args"></a>

### argument ການເປີດ CDROM
ສຳລັບ `LK_*_E* = cdrom`, argument ທີ່ຮອງຮັບແມ່ນ:
- `-nologo`
- `-nogameid`
- `-ps1fast`
- `-ps1smooth`
- `-ps1vneg`
- `-gsm=<v[:c]>`

<a id="ps2logo-arguments-ps2-discs-only"></a>

#### argument ຂອງ PS2LOGO (ສະເພາະແຜ່ນ PS2)
- ໃຊ້ `cdrom` ເປັນເສັ້ນທາງຂອງລາຍການ.
- ເພີ່ມ `-nologo` ໃສ່ argument ຂອງລາຍການເພື່ອບູດແຜ່ນ PS2 ໂດຍກົງ (ຂ້າມ `rom0:PS2LOGO`).
- ຖ້າບໍ່ມີ `-nologo`, PS2BBL ຈະເປີດແຜ່ນຜ່ານ PS2LOGO ແລະ ແພັດມັນໃຫ້ໃຊ້ພາກພື້ນຂອງແຜ່ນສະເໝີ ແລະ ຂ້າມການກວດ checksum ຂອງໂລໂກ້.
- DECKARD IE 75K ແລະ ໃໝ່ກວ່າ: XPARAM.IRX ຈະຖືກໃຊ້ອັດຕະໂນມັດເມື່ອຈຳເປັນສຳລັບການເປີດແບບບໍ່ມີໂລໂກ້.

<a id="ps1-disc-arguments-per-launch"></a>

#### argument ຂອງແຜ່ນ PS1 (ຕໍ່ການເປີດ)
ສິ່ງເຫຼົ່ານີ້ໃຊ້ກັບແຕ່ລະລາຍການ `cdrom`, ບໍ່ແມ່ນທົ່ວໄປ.
- `-ps1fast` ເປີດຄວາມໄວແຜ່ນ PS1 ແບບໄວ.
- `-ps1smooth` ເປີດການເຮັດໃຫ້ texture ລຽບ.
- `-ps1vneg` ແລ່ນ PS1DRV ຜ່ານ PS1VModeNegator. ເປັນປະໂຫຍດເມື່ອໂໝດຂອງເຄື່ອງ ແລະ ຂອງແຜ່ນຕ່າງກັນ (ເຊັ່ນ ບາງກໍລະນີ MechaPwn/modchip).

<a id="app-arguments"></a>

### argument ຂອງແອັບ
ໃຊ້ແຖວ `ARG_<BUTTON>_E? =` ເພື່ອສົ່ງ argument ໃຫ້ ELF (ເບິ່ງຕົວຢ່າງ INI).
- ໃສ່ argument ຂອງ elf ທີ່ເປີດກ່ອນ ແລ້ວເພີ່ມ argument ພາຍໃນຂອງ PS2BBL ທີ່ຕ້ອງການຕໍ່ທ້າຍ (ເບິ່ງຂ້າງລຸ່ມ). [NHDDL](https://github.com/pcm720/nhddl) ເໝາະຫຼາຍສຳລັບໃຊ້ argument ເພາະມັນເຮັດໃຫ້ NHDDL ບູດໄວຂຶ້ນ.
- `-titleid=SLUS_123.45` ແທນ ID ຫົວຂໍ້ຂອງແອັບ (ສູງສຸດ 11 ຕົວອັກສອນ).
- `-appid` ບັງຄັບ ID ເກມແບບພາບຂອງແອັບ ເຖິງວ່າ `APP_GAMEID = 0`.
- `-disc_stop` ຢຸດແຜ່ນຫຼັງໂຫຼດ ELF ເປົ້າໝາຍ (ເປັນປະໂຫຍດຕໍ່ລາຍການເມື່ອບໍ່ມີລຸ້ນສ້າງ `DISC_STOP_AT_BOOT`).
- `-gsm=<v[:c]>` ແລ່ນ ELF ເປົ້າໝາຍຜ່ານ eGSM ທີ່ຝັງໄວ້ (ບໍ່ສົນໃຈສຳລັບເສັ້ນທາງ `rom?:`). ຖ້າໃຊ້ ຕ້ອງເປັນ argument ສຸດທ້າຍ.
- `-disc_stop` ບໍ່ຖືກສົນໃຈສຳລັບລາຍການ `cdrom`.
- `-dev9=<mode>` ຕັ້ງນະໂຍບາຍ DEV9/HDD ກ່ອນເປີດ ELF ເປົ້າໝາຍ. ໂໝດທີ່ຮອງຮັບ:
  - `NICHDD` ເປີດທັງ DEV9 (ອະແດບເຕີເຄືອຂ່າຍ) ແລະ HDD ໄວ້.
  - `NIC` ເປີດ DEV9/ເຄືອຂ່າຍໄວ້, ຖອດ `pfs0:` ແລະ ໃຫ້ `hdd0:`/`hdd1:` ພັກທັນທີ.
  - ຖ້າບໍ່ໃສ່, PS2BBL ບໍ່ບັງຄັບນະໂຍບາຍ DEV9.
  - ໝາຍເຫດ: ໃນລຸ້ນສ້າງທີ່ບໍ່ມີ HDD ຕົວເລືອກນີ້ບໍ່ມີຜົນ.
- `-patinfo` ເປີດການຈັດການ PATINFO ສຳລັບລາຍການ `:PATINFO`.
  - PS2BBL ອ່ານ `SYSTEM.CNF` ຈາກພື້ນທີ່ຄຸນລັກສະນະຂອງພາທິຊັນ (`PS2ICON3D`) ແລະ ໃຊ້ `BOOT2/BOOT/path`, `arg*`, `skip_argv0` ແລະ `HDDUNITPOWER`.
  - ຖ້າ `BOOT2/BOOT/path=PATINFO`, PS2BBL ໂຫຼດ ELF ທີ່ຝັງໄວ້ຈາກພື້ນທີ່ຄຸນລັກສະນະຂອງພາທິຊັນ ແລະ ໃຊ້ການສົ່ງຕໍ່ພາຍໃນ `-la=E...`.
  - ຖ້າ `IOPRP=PATINFO` (ຫຼື ເສັ້ນທາງເອງ), PS2BBL ສົ່ງມັນໃຫ້ຂັ້ນທີ 2 ຜ່ານການສົ່ງຕໍ່ພາຍໃນ `-la=I...`.
  - ຖ້າມີ `-patinfo`, argument ທຳອິດທີ່ເຫຼືອຈະແທນເປົ້າໝາຍ `BOOT2/BOOT/path` ຂອງ CNF.
  ນີ້ແມ່ນສຳລັບລຸ້ນສ້າງ HDD.  
  ຕົວຢ່າງ PATINFO:  
    ```
    NAME_R1 = My App via PATINFO
    LK_R1_E1 = hdd0:+OSDMENU:PATINFO
    ARG_R1_E1 = pfs:/APPS/MYAPP.ELF
    ARG_R1_E1 = -patinfo               # Tells PS2BBL to use first arg as patinfo boot path.
    ```

ຕົວຢ່າງການເປີດ NHDDL ດ້ວຍໂໝດວິດີໂອ 480p ແລະ ຊອກ ISO ໃນ mmce ແລະ HDD exfat ໂດຍບໍ່ຕ້ອງໃຊ້ nhddl.yaml. ຂໍ້ດີແມ່ນບໍ່ເສຍເວລາໂຫຼດໄດຣເວີ, ຊອກ ແລະ ໂຫຼດ nhddl.yaml. ນີ້ແມ່ນວິທີໄວທີ່ສຸດທີ່ຈະບູດ NHDDL ແລະ ສະແດງລາຍການ ISO.
```
NAME_R1 = NHDDL
LK_R1_E1 = mmce?:/NEUTRINO/nhddl.elf
ARG_R1_E1 = -video=480p
ARG_R1_E1 = -mode=mmce
ARG_R1_E1 = -mode=ata
```

<a id="argument-precedence-and-order"></a>

#### ລຳດັບຄວາມສຳຄັນ ແລະ ລຳດັບຂອງ argument
1. PS2BBL ແຍກ ແລະ ໃຊ້ສະເພາະ argument ຄວບຄຸມໂປຣແກຣມໂຫຼດທີ່ຢູ່ທ້າຍ `ARG_*`: `-appid`, `-titleid=`, `-dev9=`, `-patinfo`, `-disc_stop`, `-gsm=`.
2. ການແຍກໄປຈາກລຸ່ມຂຶ້ນເທິງ ແລະ ຢຸດທີ່ argument ທຳອິດທີ່ບໍ່ແມ່ນການຄວບຄຸມ (ພຶດຕິກຳທ້າຍແບບ OSDMenu).
4. ສຳລັບເສັ້ນທາງ `:PATINFO`, PS2BBL ແຍກ `SYSTEM.CNF` ຈາກຄຸນລັກສະນະຂອງພາທິຊັນ ແລະ ຕໍ່ລາຍການ `arg*` ຂອງ CNF ຫຼັງ argument ແອັບຂອງຜູ້ໃຊ້.
5. ຖ້າຕັ້ງ `-patinfo` ແລະ ເສັ້ນທາງມີ `:PATINFO`, argument ແອັບທຳອິດທີ່ເຫຼືອຂອງຜູ້ໃຊ້ຈະກາຍເປັນເສັ້ນທາງ ELF ເປົ້າໝາຍ (ແທນເສັ້ນທາງບູດຂອງ CNF) ແລະ ຖືກເອົາອອກຈາກ argv ຂອງແອັບ. ຖ້າບໍ່ເຫຼືອ argument, ການເປີດຈະຖືກຍົກເລີກ (ຄືກັບ OSDMenu) ແລະ ບໍ່ໃຊ້ `BOOT2/BOOT/path` ຂອງ CNF.
6. argument ທີ່ເຫຼືອຮັກສາລຳດັບ ແລະ ຖືກສົ່ງໃຫ້ແອັບທີ່ເປີດ.


### eGSM (external Graphics Synthesize Mode)
ສຳລັບແຜ່ນ PS2, eGSM ຖືກອ່ານອັດຕະໂນມັດຈາກ `OSDGSM.CNF` (ບໍ່ຕ້ອງຕັ້ງເສັ້ນທາງໃນ INI). ເບິ່ງ [ທີ່ນີ້](https://github.com/pcm720/OSDMenu/blob/main/patcher/README.md#osdgsmcnf) ສຳລັບຮູບແບບໄຟລ໌ຕັ້ງຄ່າ.

- `-gsm=<v[:c]>` ແລ່ນ ELF ເປົ້າໝາຍຜ່ານ eGSM ທີ່ຝັງໄວ້ (ບໍ່ສົນໃຈສຳລັບເສັ້ນທາງ `rom?:`).
  - eGSM ໃຊ້ກັບເປົ້າໝາຍທີ່ເປີດ (ELF/ແຜ່ນ), ບໍ່ແມ່ນກັບ PS2BBL ເອງ.
  ຮູບແບບ eGSM (ແບບ OSDMenu):
- `v` = ໂໝດວິດີໂອ:
- ຫວ່າງ = ບໍ່ບັງຄັບ (ຄ່າເລີ່ມຕົ້ນ)
- `fp1` = ບັງຄັບ progressive scan (240p/288p)
- `fp2` = ບັງຄັບ progressive scan (480p/576p)
- `1080ix1` = ບັງຄັບ 1080i, ກວ້າງ/ສູງ x1
- `1080ix2` = ບັງຄັບ 1080i, ກວ້າງ/ສູງ x2
- `1080ix3` = ບັງຄັບ 1080i, ກວ້າງ/ສູງ x3
- `c` = ໂໝດເຂົ້າກັນໄດ້:
- ຫວ່າງ = ບໍ່ມີ (ຄ່າເລີ່ມຕົ້ນ)
- `1` = ການກັບ field ປະເພດ 1
- `2` = ການກັບ field ປະເພດ 2
- `3` = ການກັບ field ປະເພດ 3

ຕົວຢ່າງ ARG ຂອງ eGSM:
- `-gsm=fp2`
- `-gsm=fp2:1`
- `-gsm=1080ix2`

ຕົວຢ່າງການໃຊ້:
```
LK_TRIANGLE_E1 = mc0:/APP_WLE-ISR/WLE-ISR.ELF
ARG_TRIANGLE_E1 = -gsm=1080ix2
```
